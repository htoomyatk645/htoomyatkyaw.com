How a page of text becomes easier to read.

Bionic Redr is a Chrome extension that bolds the start of each word, surfaces the key sentences and gives dense text room to breathe. This page walks through the reading science behind it, the pipeline that runs on every page, and the design decisions that shaped version 0.3.

How it works

Three jobs, without changing a word.

Bionic Redr never rewrites the page. It reads the structure, decides what matters, and restyles text in place, so the original words, links and layout stay exactly as the author wrote them.

01

Read

A content script walks the page, skips navigation, code and forms, and splits readable text into blocks and sentences.

02

Understand

Sentence rules score topic sentences, definitions, contrasts and conclusions. The top scorers power Highlights and Key points.

03

Adapt

Word anchors, size and spacing are applied through CSS variables, and a small on-device model eases spacing where you slow down.

The pipeline

Six stages from raw page to calm page.

Every page goes through the same six stages inside the content script. Pick a stage to see what it does, a sample of what it produces, and the decision that shaped it.

DOM layer · core/dom/walker

Find the text worth reading.

The walker visits the page's text nodes and keeps only real reading content. Anything a person types into, or anything that would break if restyled, is left alone.

  • Skip the chrome. Navigation, buttons, code blocks, forms and editable areas are excluded.
  • Never read inputs. Passwords and text fields are never touched or stored.
  • Late content. A mutation observer picks up paragraphs that load after the page, like infinite scroll or chat replies.
Design decisionRestyle in place instead of replacing the page with a reader view. People keep their site, their links and their layout, and the extension never has to guess at what the author meant.

Structure layer · core/dom/structure

Split into blocks and sentences.

Readable text is grouped into headings, paragraphs, list items and quotes, then split into sentences. Each gets a stable id, so later stages can mark it without moving it.

  • Block kinds. Headings stay visible in Outline mode; paragraphs fold away.
  • Stable ids. Sentences keep their identity as the page updates, so highlights don't jump around.
  • Attributes, not wrappers. Marks are data attributes on the page's own elements wherever possible.
Design decisionStructure is computed once per block and cached by a content hash, so re-renders on busy pages cost almost nothing.

Meaning layer · core/semantic

Score what matters.

Each sentence is checked against pattern rules that mirror how skilled skimmers read: the first line of a paragraph, definitions, turns in the argument, and conclusions. The highest scorers drive Highlights and Key points.

  • Readable rules. Plain patterns like “refers to”, “however” and “as a result”, so every highlight can be explained.
  • Length sweet spot. Sentences of about 8 to 32 words score best; fragments and run-ons score lower.
  • Local first. Scoring runs in the page with no model download and no server.
Design decisionHeuristics before machine learning. They are instant, private, and predictable, and the provider interface leaves room to swap in a model later without touching the rest.

Rendering layer · core/bionic/engine

Place the word anchors.

Short words get a fixed anchor. Longer words bold a share of their letters set by the anchor strength, multiplied by the anchor-length setting.

  • Fixed short words. 1–2 letters bold one, 3–4 letters bold two, so tiny words never flicker between settings.
  • Ratios. Light 35%, Medium 45%, Strong 55%, Max 70% of each longer word.
  • Smart skips. Numbers and all-caps acronyms are left as they are.
Design decisionOne pure function decides every split, and the panel's live preview calls the same function as the page. What you tune in the panel is exactly what you get on the site.

Behaviour layer · core/behavior

Adapt to the reader's pace.

Scroll speed, dwell time, pauses and tab visibility feed a small on-device model. When you slow down on a dense passage, it adds a little line and paragraph spacing to that part of the page.

  • Bounded. Every adjustment has a hard limit, so the page can never drift far from your settings.
  • Never text size. Size is yours alone; adaptation only touches spacing and emphasis.
  • Opt-out. Smart reading can be switched off in More Settings.
Design decisionAdaptation is an overlay on top of your settings, not a replacement. Turn it off and the page snaps back to exactly what you chose.

Page layer · contents/pageStyles

Restyle without rewriting.

Settings become CSS variables on the page's root element. One stylesheet reads them, so changing a slider updates every paragraph at once without touching the DOM again.

  • Text size with zoom. New in 0.3. Each block scales with CSS zoom, so code, links and small print keep their proportions and columns still fit.
  • No compounding. Nested blocks reset to 1×, so a quote inside a list item doesn't grow twice.
  • Clean exit. Pausing a site removes every variable and attribute the extension added.
Design decisionWe chose zoom over overriding font-size because sites set sizes on nested elements. A font-size override flattened those differences; zoom keeps the site's own typography intact.
Sample · variables on :root
--bionic-redr-font-scale: 1.2; --bionic-redr-line-height: 1.7; --bionic-redr-letter-spacing: 0em; --bionic-redr-paragraph-spacing: 1em; [data-bionic-redr-block] { zoom: var(--bionic-redr-font-scale, 1); }
The science

Reading is a chain of jumps.

Your eyes stop for about a quarter of a second, jump, and stop again. You only see sharply in a small window around each stop. Press play to watch one line being read.

Live readout

Fixation 1 of 12

Pause 225 msLast jump –Sharp window 4 letters left · 15 right

An illustration built from typical values in eye-tracking research, not a recording. Short words like “to” and “and” are often skipped entirely.

Rayner, 1998

Meaning arrives during the pauses

Skilled readers make fixations of roughly 200–250 ms, separated by jumps of about 7–9 letters. Almost nothing is taken in mid-jump, so each pause has to do its work quickly.

Word anchors give every pause a clear, consistent starting point.
McConkie & Rayner, 1975

You start the next word early

The useful window reaches further right than left. Readers begin processing the start of the upcoming word before landing on it, which is why first letters carry so much weight.

Bold starts are easier to pick up in that preview. Anchor length tunes how much is bolded.
Zorzi et al., 2012 · PNAS

Tight letters crowd each other

Letters packed closely are harder to identify. Extra letter spacing helped children with dyslexia read faster and more accurately, with no training.

Text size and letter, line and paragraph spacing are all adjustable per mode.
Sweller, 1988 · cognitive load

Working memory is a small desk

Effort spent finding your place is effort not spent on meaning. Skimmers lean on topic sentences and signposts like definitions, contrasts and conclusions.

Key points keeps those sentences sharp and fades the rest.
What the evidence says

Independent tests of bolding word starts have not found a reliable reading-speed gain on average. Some readers find it more comfortable and focused; others find it distracting.

So Bionic Redr treats emphasis as a dial with an Off position, lets you pause any site, and leans on spacing and size controls, which rest on firmer research. The promise is comfort you can tune, not guaranteed speed.

The 0.3 redesign

A tool for less effort should take less effort.

Version 0.2 opened with every setting in one long scroll. Version 0.3 rebuilds the panel around the four decisions a reader actually makes mid-article, following Apple's interface conventions.

Fewer choices, faster decisions

Choice time grows with the number of options (Hick's law). The first screen keeps only what changes mid-read; tuning lives one tap away.

Version 0.2
Version 0.3
Controls visible when the panel opens: 30 in 0.2, 12 in 0.3.

A dial, not a switch

Five strengths with a big readout and −/+ buttons, because the right amount differs between people.

Private by architecture

No accounts, no servers, no analytics. Settings, reading positions and the pace model live in Chrome's local storage and can be cleared in one tap.

Show the effect, not the setting

A live preview sits above the controls, so you judge by how the text feels instead of by a percentage.

Never change the words

Every feature is styling. The author's text, links and layout stay intact, and pausing a site restores it exactly.

Familiar patterns

Switches, segmented controls and a bottom sheet follow Apple's guidelines, so nothing needs learning.

Build log

How it got here.

The interesting part of a product is usually what changed. Expand any entry for the reasoning.

May 2026Engine, modes and focus aids+
Built the word-anchor engine and DOM transformer first, then reading modes, Key points, sentence highlights and reading memory on top of the same block and sentence structure.
May 2026Behavioural and predictive layers+
Added on-device signals for scroll pace, dwell and regressions, then a forecasting layer that anticipates fatigue. Every adjustment it makes is bounded and sits on top of the user's own settings.
May 2026From popup to in-page panel+
A popup closes the moment you click the page, which made tuning impossible while reading. The settings moved into a panel that slides in beside the article and stays open.
May 2026Replaced Plasmo with esbuild+
The framework's native dependencies broke on newer Node versions. A small esbuild and Tailwind CLI build removed them and made builds near-instant.
Nov 2026Audit pass and store readiness+
Fixed a broken per-site switch and storage race conditions, tightened privacy, and added a privacy policy, a new icon, CI on every push and a Chrome Web Store guide.
Nov 2026Three design rounds+
Tried folding cards, then an editorial look, then four Apple-style prototypes (Settings lists, Books-style tiles, Control Center modules and a single dial). The single dial shipped: one big readout, plain modes, and a sheet for the rest.
Nov 2026Text size and version 0.3.0Latest+
Wired the long-dormant text size setting through to pages using CSS zoom, verified it on a real article in Chromium, and prepared 0.3.0 with new store screenshots and listing copy.
